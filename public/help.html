選択したコマに画像を入れる方法

画像を入れる ／ 分割・統合・斜めコマ ／ 背景コマ ／ 吹き出し連動・コピー ／ 保存・プロジェクト ／ ショートカット

新規漫画ページのコマに、PNG・JPEG・WebP画像を配置できます。このヘルプは別タブで開くので、編集中の画面を残したまま確認できます。

使うのは、コマを選択した後の「右側」のボタンです。
「ファイル → 新規プロジェクト → 従来どおり画像から開始」は、完成済み漫画画像を原稿として開く操作です。コマへの画像配置には使いません。
① 左側コマ選択
② 中央入れたいコマをクリック
③ 右側コマ内画像
画像を読み込む

  1. コマ割りのあるページを開く

    初めて使う場合は、上部の「ファイル → 新規プロジェクト」を押します。作品名、サイズとコマ割りを選び、「漫画ページを作成」を押してください。既に新規漫画ページを編集中なら、この手順は不要です。

  2. 画像を入れたいコマを選ぶ

    中央のキャンバスでコマの内部をクリック・タップします。枠線なしでも選択できます。新規ページでは最初のコマを自動選択します。選択したコマには点線と四隅のハンドルが出ます。左側のレイヤー一覧の「コマ 1」などからも選べます。

  3. 右側の「画像を読み込む」を押す

    右側のプロパティに「コマ内画像」が表示されます。上部の「プロパティ」横に選択中のコマ番号が表示されます。この表示は設定欄をスクロールしても残ります。設定欄の「コマ内画像」→「画像を読み込む」を押し、端末のPNG・JPEG・WebP画像を選んでください。選んだ画像がそのコマに配置されます。

  4. 「内部画像を編集」で位置を調整する

    右側の「内部画像を編集」を押し、コマ内をドラッグすると画像だけが動きます。編集中はガイドがオレンジになり、枠のハンドルは隠れます。画像の大きさは拡大率スライダー・数値入力で調整できます。

スマートフォンの場合
画面のコマを直接タップできます。コマをタップした後、上部の「プロパティ」を押すと、画像を読み込む設定が開きます。画像の位置はタッチドラッグ、倍率はスライダーで調整できます。

画像の見え方を変える

Cover縦横比を維持してコマ全体を埋めます。コマからはみ出た部分は隠れます。画像読込時の初期配置です。
Contain画像全体が見えるよう中央へ配置します。コマとの比率が違う場合は余白ができます。
表示位置をリセット現在の倍率を保ったまま、画像をコマの中央へ戻します。
初期倍率へ戻す現在のCover／Contain方式とコマ寸法に合わせた倍率へ戻します。
コマに合わせ直す現在のCover／Contain方式で、倍率と位置をまとめて合わせ直します。
画像を変更／画像を削除差し替えや削除ができます。画像を削除してもコマ枠は残ります。

コマ枠そのものを動かしたいとき

「コマ枠を編集」へ戻します。枠をドラッグすると内部画像も一緒に移動します。四隅で枠のサイズを変えた場合は、画像の位置・倍率を保ち、見える範囲だけを変更します。吹き出しを編集する場合は、その吹き出しを選択してください。

「画像を読み込む」が見つからない場合

  • 右側が「セリフ」になっている場合は、吹き出しが選択されています。「コマ選択」に切り替えて、コマを選び直してください。
  • コマ編集のない完成済み画像モードでは、この機能は使えません。「ファイル → 新規プロジェクト」から漫画ページを作成してください。
  • 画像が既に入っているコマでは、ボタン名が「画像を変更」になります。

分割・統合・斜めコマを作る

コマを選ぶと、右側に「コマ形状・構成」が表示されます。内部画像を操作するときは「内部画像を編集」、形状を操作するときは「コマ枠を編集」または「頂点編集」を使います。

  1. 分割：「分割位置（%）」を10〜90%で指定し、左の「左右に分割」（縦方向の分割線で左・右の2コマ）または右の「上下に分割」（横方向の分割線で上・下の2コマ）を押します。ガターを挟んだ2コマになります。画像は同じ素材を参照し、構図を保ちます。分割後の画像はそれぞれ動かせます。
  2. 統合：上部の「プロパティ」横で統合元のコマ番号を確認し、「コマを統合」を押します。統合元は青、候補は緑の破線と✓（そのまま統合）、黄色の点線と△（サイズ調整あり）で表示されます。候補を画面でクリックしてください。吹き出しが重なっていても選べます。両方に画像がある場合は使用する画像を選びます。サイズ調整がある場合は、変更前後の位置・寸法と変更する端を確認して「サイズを揃えて統合」を押します。確認するまではデータを変更しません。Esc・キャンセルで終了できます。
  3. 斜めコマ：「頂点編集」を押し、紫の丸をドラッグします。各頂点だけが動き、画像の位置・倍率は維持されます。辺が交差する位置や細すぎる形には変更できません。「頂点を初期位置に戻す」「長方形に戻す」で戻せます。

統合は隣接する通常の長方形コマが対象です。統合元を固定し、相手の高さ（左右統合）または幅（上下統合）だけを合わせます。寸法差と両端のずれが、それぞれ統合元寸法の10%以内、かつ50px以内であることが条件です。離れたコマ・斜めコマ・調整によって別のコマへ重なる組み合わせは候補にしません。

分割・統合・頂点ドラッグは取り消し／やり直しに対応します。サイズ合わせと統合は1回の取り消しで両方復元します。統合で表示に採用しなかった画像も、取り消しで復元できます。

画像を背景に使う

通常コマの内側はページ背景色で下塗りし、その上にコマ内画像を表示します。空のコマや透明PNGの透明部分に、背面の背景画像は透けません。背景画像は背景コマ自身の領域や、表示を許可したコマ間に見えます。

右側の「コマ種別」を「画像コマ（背景）」にすると、画像と位置・倍率を保ったまま通常コマの後ろへ移ります。初期状態では枠線なし・画像クリッピングOFFです。枠線とクリッピングは別々に切り替えられます。

背景が見えないとき
左側のページ設定で「コマ間の背景を表示」をONにしてください。OFFでは、通常コマと画像入り背景コマの領域外をページ背景色で覆います。背景コマ自身の輪郭内は隠しません。通常コマが1つもない場合は、背景だけを表示します。

背景コマの画像も「内部画像を編集」で移動・倍率調整できます。背景コマの分割・統合・頂点編集は今回の対象外です。必要なら「通常コマ」に戻して操作してください。

編集内容を保存する

上部ツールバーの「保存」で作品フォルダへ保存します。フォルダ非対応ブラウザではZIPをダウンロードします。バックアップは「ファイル → プロジェクトZIPをバックアップ」、旧ZIPの読込は「ファイル → ZIPからプロジェクトを復元」です。完成原稿は上部の「PNG書き出し」から出力します。

コマと吹き出しを連動させる

  1. コマを選んでから吹き出しを追加すると、そのコマに所属して中央付近へ配置されます。しっぽを含め、可能な限りコマ内へ収めます。小さなコマでも文字や本体を勝手に縮小しません。
  2. 吹き出しは画面で直接選べます。所属コマは上部の「プロパティ」横に表示され、設定欄の「所属コマ」から変更できます。他のコマへドラッグしただけでは所属は変わりません。
  3. 「コマ連動トリミング」をONにすると、本体・しっぽ・文字全体を所属コマの輪郭で切り抜きます。OFFにすると枠はみ出し表示ができます。通常コマへの新規作成はON、背景コマはOFFです。手動クリッピングも残り、手動範囲を適用した後にコマ輪郭で切り抜きます。
  4. コマを移動すると所属する吹き出しも移動します。コマのサイズ変更では相対位置が追従し、吹き出し・文字のサイズや装飾は維持します。頂点編集では位置を動かさず、トリミング輪郭だけが変わります。
  5. コマを選ぶと右パネルに所属する吹き出し一覧が出ます。コマのハンドルは吹き出しより前面にあり、重なっていても操作できます。

別のコマへコピーする

  1. 吹き出しを選び、「コピー」を押します。コピー横の展開ボタン →「書式のみコピー」ならセリフ本文を空にして形状・文字書式・装飾をコピーします。
  2. 貼り付け先のコマをクリックし、上部ツールバーの「貼り付け」を押します。元コマ内の相対位置を基準に、新しいIDで作成します。吹き出し・文字のサイズ、回転、しっぽ、トリミング設定を保持します。

Ctrl / ⌘ C・Vでも操作できます。セリフなどの入力欄では通常の文字コピー・貼り付けを優先します。コピーはこのアプリ内の一時データです。Ctrl / ⌘ Dによる従来の複製も使えます。

分割・削除と保存

分割時は吹き出し中心が入る側へ所属を引き継ぎます。中心がガターやコマ外の場合は所属先を選んでから確定します。統合では両コマの吹き出しを位置・文字の変更なしに引き継ぎます。

吹き出しがあるコマを削除すると「コマと所属する吹き出しを削除」「吹き出しを残して所属解除」「キャンセル」を選べます。取り消しで復元できます。

所属・トリミング・画像・コマ割りは通常保存またはZIPバックアップで保存できます。セリフ設定JSONは従来どおり画像やコマ割りを含みません。同じIDのコマがない場合は所属先を後から指定でき、文字や位置を自動変更しません。古いページの所属なし吹き出しもそのまま編集できます。完成済み漫画画像の編集は画像全体を仮想コマとして扱います。

作品フォルダと継続保存

  1. 初回の「保存先フォルダの設定」で既定の親フォルダを選択します。後で設定しても編集できます。設定は「ファイル → 保存先フォルダの設定」から変更できます。
  2. 「ファイル → 新規プロジェクト」で作品名とページを作ります。最初の「保存」で名前を確認すると、指定した親フォルダ内に作品フォルダを作成します。同名のフォルダには無断で上書きしません。名前の変更または既存プロジェクトを開く操作を選んでください。
  3. 次からは「保存」またはCtrl / ⌘ Sで同じ作品を更新します。「名前を付けて保存／複製」は別の作品フォルダを作ります。
  4. 次回は「ファイル → 最近使ったプロジェクト」または「プロジェクトを開く」で作品フォルダを開きます。ブラウザの保存先記憶が消えた場合は、フォルダを再指定してください。
  5. 権限が失効した場合は、保存先設定の「保存先へのアクセスを再許可」を押します。許可するまでは書き込みません。保存失敗はヘッダーとエラー表示で通知し、編集内容を保持します。

ヘッダーには作品名・ページ名と「保存済み／未保存の変更あり／保存中／保存失敗／保存先への再許可が必要」を表示します。保存は手動です。未保存の変更がある場合、ブラウザが対応する範囲で離脱を警告します。

project.json作品ID、形式バージョン、ページ一覧、素材参照。ページを複数格納できる形式ですが、現在の編集画面は1ページずつです。
pagesコマ・吹き出し・文字などのページ編集原本。更新ごとの世代を保持します。
images加工していない元画像。同じ内容の素材は可能な限り共有します。
dialogue「ファイル → セリフ設定JSONを書き出す」の出力先。ページ編集原本とは別の交換用データです。「JSONをダウンロード」も使用できます。
exports完成PNG。既存ファイルがある場合は連番で保存します。
backupsZIPバックアップと、直前の正常な参照情報。旧世代の自動削除は行いません。

フォルダ保存は対応するChromeなどで利用できます。非対応環境ではZIP保存・復元、PNG・JSONダウンロードを使用してください。ZIP復元だけで既存作品フォルダを上書きすることはありません。最初のフォルダ保存前のPNG・JSONはダウンロードになります。

ショートカットとIME

保存：Ctrl / ⌘ S、取り消し：Ctrl / ⌘ Z、やり直し：Ctrl / ⌘ Shift Z（従来のCtrl / ⌘ Yも維持）、コピー：Ctrl / ⌘ C、貼り付け：Ctrl / ⌘ V、複製：Ctrl / ⌘ D、削除：Delete / Backspace、統合解除：Esc。Space＋ドラッグによる画面移動も維持します。

入力欄・数値欄・contenteditable内では文字入力を優先します。日本語IMEの変換中と確定直後には編集ショートカットを実行しません。入力欄のコピー・貼り付け・Undoはブラウザに任せます。

Alt V（選択）・Alt H（画面移動）・Alt Q（楕円）・Alt R（角丸四角）・Alt T（文字のみ）・Alt G（ギザギザ）・Ctrl / ⌘ Shift E（PNG）は候補・実機未検証のため既定では無効です。アプリ上部「ヘルプ」で試用を明示的に有効にできます。競合する環境では無効のまま画面ボタンを使ってください。Alt E/Fや単独アルファベットには割り当てません。

整理後のパネル

左側は基本操作 → 吹き出し追加 → コマ操作 → レイヤーです。コマ割り・ページ設定は折りたたみ内にあります。保存・コピー・貼り付け・複製・削除・Undo/Redoは上部へ移しました。

右側は文字サイズ・縦横・所属・トリミングを常時表示します。文字詳細、装飾、形状、しっぽ、手動クリップ、回転、座標は個別に開けます。コマの画像位置、Cover/Contain・リセット、頂点編集、座標、枠線色なども折りたたみ内です。開閉状態は選択を変えても維持します。

自動保存はありません。画像は端末内で処理し、元画像を破壊的に切り取りません。元の編集画面には、このタブを閉じて戻ってください。
