# Comic-Lab v2.0-alpha.3 — 自由コマ割り

開発ブランチ: `feature/v2-panel-layout`。

プレビュー: https://feature-v2-panel-layout-comic-lab.kairi-sakusaku.workers.dev/

復帰基準はalpha.2の正常時点 `903c6ab18bd93285e4e74f20379bea76f3b6e711`。その後のv2.1ヘルプ追加時点 `50f650e` を維持して開発しました。main・本番Workers・旧Pages・Wranglerプレビュー設定・シークレットは変更しません。

## 操作

新規ページのコマを選び、右の「コマ形状・構成」を使用します。既存の上部ヘルプにも操作説明を追加しています。

- **左右に分割・上下に分割**: 位置10〜90%（初期50%）と方向を指定。ページのガターを内側へ適用し、2コマを作ります。4頂点では向かい合う辺を同じ比率で分けるため、斜めコマの分割線は辺に沿って傾くことがあります。最小サイズを満たさない分割は理由を表示して中止します。
- 分割画像は素材を共有し、原稿上の画像位置・倍率を維持。個別のimageデータを持ち、片方を動かしても他方は動きません。新しい2つの通常コマはクリッピングONとなり、分割形状とガターに沿って表示します。元の設定はUndoで戻ります。
- **統合**: 「統合相手」で2つ目の通常コマを選びます。相手を金色の点線で表示します。画像が両方にある場合は、使用する画像の明示選択後に「コマを統合」を実行できます。片方だけに画像があればその画像を維持します。
- 統合できるのは、内側の辺が平行に隣接し、外形が長方形になる2コマです。ガター以下の隙間は許可。長方形同士のほか、補完する台形同士にも対応します。L字・不規則形・遠く離れたコマ・背景コマは不可で理由を表示します。
- 統合後の枠線と表示設定は主選択コマから継承。採用画像は位置・倍率・比率を維持します。元の2コマと不採用画像は、セッション内のUndoで復元できます。
- **頂点編集**: 「頂点編集」を押し、紫の丸をドラッグ。1つの頂点だけを動かします。画像は変形・再フィットせず、原稿上の位置と倍率を維持します。操作領域は表示倍率によらず直径36pxです。
- 交差・反転・凹形状・極端に細い形・ページ外の移動は制限。無効な位置では直前の有効状態を維持します。「頂点を初期位置に戻す」は最初の頂点変更前の輪郭へ戻し、「長方形に戻す」は現在の外接矩形へ戻します。復元輪郭はコマ移動・サイズ変更にも追従し、必要ならページ内に収めます。
- 「コマ枠を編集」「内部画像を編集」「頂点編集」は独立したUI状態です。内部画像操作で頂点は変わりません。頂点編集中は本体のドラッグ移動を止め、ハンドルから操作します。

## 背景コマ

- 「コマ種別」で通常／画像コマ（背景）を切り替え。画像素材・座標・倍率を保持します。切替時は通常が枠線ON・クリップON、背景が枠線OFF・クリップOFF。
- 枠線と「画像をコマの形でクリッピング」は別設定。背景でもクリップを有効にできます。OFFでは画像をそのまま表示し、ページ外だけは描画対象外です。
- 描画順はページ色 → 背景コマ画像・枠 → 必要に応じた余白マスク → 通常コマ画像 → 通常コマ枠 → セリフ。レイヤー内は保存したorderを維持します。
- 左側の **「コマ間の背景を表示」** は初期OFF。OFFは通常コマの多角形の外側（外周余白も含む）をページ背景色で覆います。通常コマの内側は背景が見えるため、画像未設定コマも透明な窓として扱います。ONではコマ間と外周にも背景が見えます。
- 通常コマがゼロの場合はコマ間がないためマスクせず、背景だけのページを表示します。テンプレートの再適用は通常コマを置き換え、背景コマと吹き出しは保持します。
- 背景コマの分割・統合・頂点編集は対象外。通常へ戻すと操作できます。移動・サイズ変更・画像編集は背景でも可能です。

## モデルと互換性

v2プロジェクトを任意項目で拡張しました。

- Panel.kind: `normal | background`。
- Panel.points: 原稿座標の凸四角形4頂点。順序は左上・右上・右下・左下に対応する周回順を維持し、正の巻き方向のみ許可。
- Panel.clipImage: 未指定ならnormalはtrue、backgroundはfalse。
- Panel.resetPoints: 頂点編集を始める前の復元輪郭。変更を始めたときだけ保存します。
- PageSettings.showGutterBackground: 未指定ならfalse。

旧v1.55・alpha.1・alpha.2では頂点・画像・枠線を変更せず、未指定項目を描画時に既定扱いします。読み込みだけで新項目を強制挿入しません。

ポリゴンの外接矩形を画像の相対座標基準として使い、形状編集時には原点差をオフセットで補正して画像位置を保持します。移動・外接矩形リサイズでも四角形の輪郭を維持します。

画像素材はalpha.2の方式を再利用。分割で重複保存せず、統合で使わなくなった素材は履歴キャッシュへ保持。ZIPは使用中素材を保存し、履歴そのものは保存しません。セリフJSONは引き続きセリフ専用です。

## Stepごとの確認と最終検証

1. 既存モデル・保存処理を調査し、復帰コミットを記録。凸四角形・背景種別・任意設定を追加。
2. 頂点の独立移動、画像位置の補正、自己交差・反転・縮退防止、移動・リサイズ・復元輪郭を検証。
3. 両方向・指定比率の分割、ガター、素材共有と画像の独立編集、最小サイズによる拒否を検証。
4. 長方形および補完する台形の統合、画像の明示選択、不正条件の理由、Undo/Redoを検証。
5. 背景の固定レイヤー順、枠線とクリップの独立、ガター表示、実ZIP復元を検証。
6. 最終137件の `npm test`、`npm run build`（TypeScript検査込み）、`git diff --check` が成功。

実際のAppハンドラーで、分割→画像選択→統合、ズームとSVG原点を反映した頂点ドラッグ、無効位置の拒否、ドラッグ1回のUndo、背景設定を含むZIP再読込を確認しています。

独立SVGラスタライザーで1200×1200pxのページをPNG化し、斜めコマの内外、背景ON/OFF、外周余白、透明な通常コマ内部、分割ガター、ZIP復元前後のPNG完全一致をピクセルで検証しました。v1.55・alpha.1・alpha.2の検証PNGも改修前と完全一致しています。編集ハンドル・ガイドは出力SVGに含めません。

## 未確認事項・既知の制限

この環境には実ブラウザ操作ツールがありません。実機マウス／タッチの捕捉、IME、実ダウンロード、ブラウザCanvas生成の最終一致は未確認です。AppハンドラーテストのDOM・画像デコードは代替を使用し、独立ラスタライザーでのPNG検証とは区別しています。

統合は2コマのみ、現在のページガター以内の隣接と長方形外形に限定します。頂点は独立操作で、隣接コマは自動追従しません。通常コマに画像がなければ背後の背景を透過します。

分割・統合・頂点操作・種別変更・背景設定をUndo/Redoし、PNGと編集画面の一致をプレビューで確認してから正式統合します。コマと吹き出しの親子関係、台詞追従、自動クリッピング、コマ間コピー、曲線・5頂点以上、AIは追加していません。
