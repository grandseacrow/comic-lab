# 手動受入確認

自動テストで確認できない、実ブラウザでの最終確認手順です。

1. 1000×1400pxなど寸法が既知のPNG・JPEG・WebPをそれぞれ読み込み、縦横比・原寸情報を確認。
2. 楕円・角丸四角を合計5個以上追加。選択、ドラッグ、拡縮、数値入力、複製、削除、前後変更、Undo/Redoを確認。
3. A/B/Pを四方へ動かす。しっぽを反転し、本体サイズを変えても接合線が出ないことを確認。
4. 「こんにちは。」「ゃゅょっ」「ー」「（括弧）」「AI2026」、複数行、長文、明朝、太字を縦横で確認。IME変換中に入力が途切れないことを確認。
5. 文字はみ出しを発生させて警告を確認。文字サイズが自動縮小されないことを確認。
6. 背景の人物や構図が、セリフ変更によって変化しないことを確認。
7. ZIP保存し、ページ再読込後にZIPを開く。元画像、セリフ、しっぽ、書式、描画順を比較。
8. PNGを出力して元画像と同じ寸法であることを確認。画面と文字・しっぽの位置を比較。選択枠・ガイドが入らないことを確認。
9. 不正ZIP・破損画像を読み込み、エラー後も現在の編集が維持されることを確認。
10. 未保存状態で画像差し替え・ZIP読込・ページ離脱を試し、警告を確認。
11. 50%と100%表示でそれぞれ出力し、原稿寸法と描画内容が同じであることを確認。
12. Chrome / Edgeで確認後、Safariとスマートフォン実機のタッチ・ダウンロードを確認。

ブラウザ操作ツールが提供されない実装環境では、これらを未確認として記録します。

## v0.1.1の追加手順

1. 通常選択時は文字枠が見えず、文字入力中または「文字枠だけ編集」時だけ薄い点線が出ることを確認。
2. 操作対象を切り替え、本体＋文字、本体だけ、文字枠だけを移動。文字枠をリサイズ後、本体をリサイズしても文字枠が変わらないことを確認。
3. 縦書き・横書きで文字サイズを大きくし、「そのまま表示」で縮小・クリッピングされずPNGに出ることを確認。原稿の外はPNGに含まれないことを確認。
4. 「サイズを維持して警告」を選び、文字枠・本体からのはみ出し通知を確認。PNG出力が可能なことを確認。
5. 「入力した改行のみ」でサイズ変更しても改行が増えないことを確認。自動フィットを選び、指定サイズと表示サイズが別表示されることを確認。文字枠位置・改行を保ち、解除時に元サイズへ戻ることを確認。
6. 角丸を0・中間・100%に変更し、しっぽ接合とサイズ変更後の割合を確認。楕円ではスライダーが無効なことを確認。
7. 両形状でしっぽの表示切替。オフ時は制御点が消え、オン時に前のA/B/P位置に戻ることを確認。
8. 旧ZIPを読み込み、元画像・セリフ・配置・既存しっぽ設定の一致を確認。
9. 新設定を含むZIP保存・再読込、PNG出力、Undo/Redoの結果を比較。


## v1.2の「文字のみ」

1. 左の作成ツールに楕円・角丸四角・文字のみの3種類があり、幅に応じて3列または折り返しになることを確認。
2. 漫画画像上へ文字のみを追加。背景・枠線・しっぽがなく、選択中の文字領域からドラッグ移動・右下でリサイズできることを確認。
3. 文字のみのプロパティに形状・塗り色・線・角丸・しっぽ設定が出ず、縦横・文字サイズ・フォント・色・領域寸法を編集できることを確認。
4. 大きい日本語を領域からはみ出させ、指定サイズが保たれることを確認。ゴシック・明朝と縦書き・横書きで確認。
5. 混在レイヤーの選択・前後変更・複製・削除・Undo/Redoを確認。
6. ZIP保存後に再読込。文字のみの状態・位置・書式・順序が維持され、従来の吹き出しも同じ表示になることを確認。
7. PNGを開き、文字のみの周囲に背景・枠・しっぽ・編集ガイドが出ず、元画像が透けていることを確認。

実ブラウザ操作ツールがない環境では上記操作は未確認とし、自動テストと共通SVGのPNGラスタライズ結果を別に記録します。
