# 手動受入確認

自動テストで確認できない、実ブラウザでの最終確認手順です。

1. 1000×1400pxなど寸法が既知のPNG・JPEG・WebPをそれぞれ読み込み、縦横比・原寸情報を確認。
2. 楕円・角丸四角を合計5個以上追加。選択、ドラッグ、拡縮、数値入力、複製、削除、前後変更、Undo/Redoを確認。
3. A/B/Pを四方へ動かす。しっぽを反転し、本体サイズを変えても接合線が出ないことを確認。
4. 「こんにちは。」「ゃゅょっ」「ー」「（括弧）」「AI2026」、複数行、長文、明朝、太字を縦横で確認。IME変換中に入力が途切れないことを確認。
5. 文字はみ出しを発生させて警告を確認。文字サイズが自動縮小されないことを確認。
6. 背景の人物や構図が、セリフ変更によって変化しないことを確認。
7. ZIP保存し、ページ再読込後にZIPを開く。元画像、セリフ、しっぽ、書式、描画順を比較。
8. PNGを出力して元画像と同じ寸法であることを確認。画面と文字・しっぽの位置を比較。選択枠・ガイドが入らないことを確認。
9. 不正ZIP・破損画像を読み込み、エラー後も現在の編集が維持されることを確認。
10. 未保存状態で画像差し替え・ZIP読込・ページ離脱を試し、警告を確認。
11. 50%と100%表示でそれぞれ出力し、原稿寸法と描画内容が同じであることを確認。
12. Chrome / Edgeで確認後、Safariとスマートフォン実機のタッチ・ダウンロードを確認。

ブラウザ操作ツールが提供されない実装環境では、これらを未確認として記録します。

## v0.1.1の追加手順

1. 通常選択時は文字枠が見えず、文字入力中または「文字枠だけ編集」時だけ薄い点線が出ることを確認。
2. 操作対象を切り替え、本体＋文字、本体だけ、文字枠だけを移動。文字枠をリサイズ後、本体をリサイズしても文字枠が変わらないことを確認。
3. 縦書き・横書きで文字サイズを大きくし、「そのまま表示」で縮小・クリッピングされずPNGに出ることを確認。原稿の外はPNGに含まれないことを確認。
4. 「サイズを維持して警告」を選び、文字枠・本体からのはみ出し通知を確認。PNG出力が可能なことを確認。
5. 「入力した改行のみ」でサイズ変更しても改行が増えないことを確認。自動フィットを選び、指定サイズと表示サイズが別表示されることを確認。文字枠位置・改行を保ち、解除時に元サイズへ戻ることを確認。
6. 角丸を0・中間・100%に変更し、しっぽ接合とサイズ変更後の割合を確認。楕円ではスライダーが無効なことを確認。
7. 両形状でしっぽの表示切替。オフ時は制御点が消え、オン時に前のA/B/P位置に戻ることを確認。
8. 旧ZIPを読み込み、元画像・セリフ・配置・既存しっぽ設定の一致を確認。
9. 新設定を含むZIP保存・再読込、PNG出力、Undo/Redoの結果を比較。


## v1.2の「文字のみ」

1. 左の作成ツールに楕円・角丸四角・文字のみの3種類があり、幅に応じて3列または折り返しになることを確認。
2. 漫画画像上へ文字のみを追加。背景・枠線・しっぽがなく、選択中の文字領域からドラッグ移動・右下でリサイズできることを確認。
3. 文字のみのプロパティに形状・塗り色・線・角丸・しっぽ設定が出ず、縦横・文字サイズ・フォント・色・領域寸法を編集できることを確認。
4. 大きい日本語を領域からはみ出させ、指定サイズが保たれることを確認。ゴシック・明朝と縦書き・横書きで確認。
5. 混在レイヤーの選択・前後変更・複製・削除・Undo/Redoを確認。
6. ZIP保存後に再読込。文字のみの状態・位置・書式・順序が維持され、従来の吹き出しも同じ表示になることを確認。
7. PNGを開き、文字のみの周囲に背景・枠・しっぽ・編集ガイドが出ず、元画像が透けていることを確認。

## v1.3の文字装飾

1. 文字のみで黒文字＋白フチ、白文字＋黒フチを設定。文字サイズ・倍率を変えても原稿単位の太さが反映され、本体をつぶさないことを確認。
2. 影のオン／オフ、色、正負のX/Yオフセット、ぼかし0と最大値を確認。フチと同時使用する。
3. 縦書きの括弧・句読点・長音符・英数字、横書き、ゴシック・明朝で確認。
4. 楕円・角丸四角のセリフにも装飾を設定し、本体・しっぽの操作が維持されることを確認。
5. 文字領域を小さくし、大文字とフチ・影をはみ出させる。PNGに装飾が入り、文字領域に沿った欠けがないことを確認。原稿外は出力されない。
6. ZIP保存・再読込後に全装飾値とPNGを比較。複製・Undo/Redoでも値を確認。
7. v1.2以前のZIPを読み込み、装飾が無効で、既存の位置・サイズ・色・文字内容・背景を維持することを確認。

実ブラウザ操作ツールがないため、上記のブラウザ操作は未確認。自動テストと、共通SVGを別のラスタライザでPNG化した結果はREADMEに記録。


## v1.4のセリフ設定JSON

1. 画像上に楕円・角丸四角・文字のみを配置。縦横、フォント、装飾、しっぽ・角丸・順序を設定してJSON保存する。
2. JSONに形式・バージョン・画像寸法と全オブジェクトがあり、画像データが含まれないことを確認。
3. 別セッションで同じ寸法の画像を開きJSON読込。確認画面でキャンセルしても現在の編集が残ることを確認。置換後の全設定・PNGを比較。
4. 異なる寸法の画像で警告を確認。「比例変換」「座標そのまま」をそれぞれ選んで位置・文字サイズ・装飾を比較。
5. 表示倍率を変えて同じJSONを読み込み、原稿座標と出力寸法が倍率に影響されないことを確認。
6. JSON置換後にUndo/Redo。背景画像・タイトル・表示倍率が維持されることを確認。
7. 不正構文、必須項目欠落、未知の種類・バージョン、重複ID、過大ファイルを選択。理由が出て、現在の原稿が消えないことを確認。
8. 比例変換が対応範囲を超えるデータで適用失敗を確認。数値を無断で変更せず、「座標そのまま」へ切り替えて読み込めることを確認。
9. 旧設定（装飾などの新規フィールドなし）で従来の既定値補完を確認。従来のZIP保存・読込も通す。
10. スマートフォンのツールパネルからJSON操作を開き、確認ダイアログを操作できることを確認。

ブラウザ操作ツールがない環境では上記操作は未確認。共通シリアライザ・復元処理・SVGからのPNG比較は自動検証として別途記録。


## v1.5の総合確認

1. セリフ欄と直下の循環ボタンが常時表示され、6グループが初期状態で閉じていることを確認。複数を開き、選択変更・文字のみ選択・元に戻す操作で開閉状態の保持を確認。
2. 吹き出し／文字のみ／文字と吹き出しの順序、文字のみオブジェクトでの固定、種類や表示が切り替わらないことを確認。モード・開閉を変えてUndo履歴が増えないことを確認。
3. 4種類で正負のドラッグ回転、数値角度、0度リセット。文字と本体を個別・一体に回転し、しっぽの追従と個別角度差を確認。
4. 回転後に移動・本体リサイズ・文字領域リサイズ・A/B/P調整。異なる表示倍率でも原稿座標が一致し、反対側の角が動かないことを確認。
5. ギザギザの数・深さ・尖り具合を端値へ変更。しっぽあり／なし、方向変更、接合線や穴が出ないことを確認。
6. クリップを有効にし、点線範囲を移動して4隅を変更。オブジェクトを動かしても範囲が原稿位置に固定されることを確認。
7. 本体＋しっぽのみ／文字も含めるを切り替え、回転や装飾込みの結果を比較。クリップ無効で元形状へ戻ることを確認。
8. JSON／ZIP保存・読込、寸法違いのJSON比例読込、Undo/Redo、PNG出力を通す。原稿外以外の意図しない欠けや編集ガイドが入らないことを確認。
9. 旧ZIP／JSONで回転0度・クリップ無効となり、既存表示が維持されることを確認。新しいショートカットが追加されていないことを確認。

実ブラウザ操作ツールがない環境では上記操作は未確認。座標演算・SVG生成・PNG比較による自動検証をREADMEに別記しています。
