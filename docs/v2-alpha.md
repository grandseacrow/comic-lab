# Comic-Lab v2.0-alpha.1

基準: v1.55 (`9855251`)、開発ブランチ: `feature/v2-panel-layout`。
本番: https://comic-lab.kairi-sakusaku.workers.dev 。mainへのマージ・本番デプロイはユーザー確認後です。

## 各Stepの結果

1. **ページモデル**: 新規ページをプロジェクト形式v2に分離。ページ設定、4頂点のコマ、将来の素材参照・所属コマIDを追加。旧v1にはページ情報を追加しません。99件のテストとビルド成功。
2. **テンプレート**: データ定義から上下／左右2コマ、縦4コマ、2×2、空白を生成。3つのページサイズで余白・ガターを検証。102件のテストとビルド成功。
3. **基本コマ編集**: 原稿座標で移動、四隅リサイズ、最小40px、ページ内への制限、追加・削除・履歴。106件のテストとビルド成功。
4. **吹き出しとの共存**: 背景→コマ→セリフの描画、コマ編集と吹き出し編集の選択分離、元のプロパティ開閉状態の保持。実際のAppハンドラーを通すテストを追加。108件のテストとビルド成功。
5. **保存・出力**: 既存のZIPシリアライズ・復元とPNG用SVGを拡張。新規ページのZIP実ファイル往復、セリフJSONでコマを変更しないこと、PNGの原寸とガイド除外を検証。最終112件のテストとビルド成功。

さらに1200×1800pxの4コマに楕円・角丸・ギザギザ・文字のみを重ねたSVGを独立したラスタライザーでPNG化し、背景色・枠色・ガターのピクセルとZIP復元前後のPNG完全一致を確認しました。従来の回転・ギザギザ・手動クリッピングを含む検証PNGも改修前とバイト単位で一致しています。

実ブラウザ用の操作ツールが環境にないため、マウス／タッチでのポインター捕捉、スクロール・パン、IME、実ダウンロード、ブラウザCanvas生成は未確認です。ハンドラーテストのDOM参照・ダウンロードとCanvasパイプラインのテストは代替オブジェクトを使用しています。独立ラスタライザーでの一致はブラウザでの最終確認とは別です。

## 操作

1. 「新規作成」→サイズと初期コマ割り→「漫画ページを作成」。既存画像を開く場合は「従来どおり画像から開始」。
2. 左の「コマ編集」→「コマ選択」でコマ内をクリック。通常の吹き出し選択時もコマ枠線をクリックして選択できます。非表示の枠はコマ選択ツールかレイヤー一覧から選択します。
3. ドラッグでコマ移動、四隅の□でサイズ変更。右のプロパティでX・Y・幅・高さ・枠線を編集します。
4. 「通常コマを追加」は見えている原稿位置へ追加。「選択コマを削除」は吹き出しを維持します。
5. 「選択」ツール、吹き出しレイヤーの選択、または吹き出し追加で既存のセリフ編集へ戻れます。
6. ページ余白・コマ間隔は次のテンプレート適用時に反映します。適用時は現在のコマだけ置き換え、既存の吹き出しは保持します。
7. ページサイズの変更はコマ座標を縦横に比例変換してページ内へ収めます。吹き出し座標・文字サイズは維持します。
8. ページ全体の再編集はプロジェクトZIPで保存します。セリフ設定JSONにはページ背景・コマ配列を含めません。

コマ分割・統合・斜め変形・コマ内画像・吹き出し追従・自動クリッピングは未実装です。既存ショートカットの新規追加・割当変更はありません。

## データ

- 画像編集: `version:1`、従来のbackgroundとballoons。
- 新規ページ: `version:2`、backgroundはnull、`page:{mode:'new-page', backgroundColor, margin, gutter, template}` と `panels:[]` を追加。
- コマ: ID、kind、shape、4頂点、order、枠線設定、assetId、editingを保持。alpha.1では軸に平行な長方形を検証します。
- 吹き出しの任意 `panelId` は将来用のデータ枠です。自動関連付け・移動連動は行いません。
- ZIPは既存のproject.jsonを拡張。新規ページは画像ファイルなしでも復元できます。従来画像の元バイト列は変更しません。
- 未対応形式・不正な頂点・未知のコマ種類は拒否し、現在の原稿は保持します。
- セリフJSONの形式v1/v2と読み込み時の寸法確認は維持します。JSONでセリフを置き換えてもページとコマは保持します。
- 選択・倍率・ツール・プロパティ開閉・Undo/Redo履歴は保存しません。

## Cloudflare Workersでalphaを確認する

現在のCloudflare設定は外部管理です。この作業環境からWorkersのビルド設定を参照・変更できないため、確認用URLはまだ発行していません。古いPages用ActionsワークフローやSitesの本番は変更していません。

1. Cloudflareダッシュボードの **Workers & Pages → comic-lab → Settings → Builds** を開きます。
2. 本番ブランチは **main** のまま、ブランチ制御で **非本番ブランチのビルド／プレビュー** を有効にします。対象を選べる場合は `feature/v2-panel-layout` を追加します。表示名はCloudflareの画面により異なります。
3. ビルドは `npm run build`、静的アセットは `dist`。現在の本番設定の値を確認して使用します。非本番の処理は **バージョンアップロード（versions upload）** とプレビューURLを使い、本番トラフィックを切り替えるデプロイは実行しません。
4. 対象ブランチのビルドを開始し、Cloudflareが表示した **Preview URL** を開きます。画面下の版が **v2.0-alpha.1** であることを確認します。本番URLがv1.55のままかも確認します。
5. プレビューの設定が不明な場合は、mainのデプロイ設定を変更せず、CloudflareのBuilds画面で現在値を確認してから進めてください。

GitHubのPRではCIがテスト・ビルドを実行し、`comic-lab-review-build` という静的ビルドをArtifactsへ14日間保存します。成果物のダウンロード自体はWeb公開ではありません。ローカル確認はこのブランチで `npm ci` → `npm run dev` でも実施できます。

## 手動受入確認

- 3サイズ×5テンプレートで新規作成。余白・間隔・背景色を変更して再適用。キャンセルで元のコマが維持されること。
- ズーム・スクロール・パン後にコマ選択、移動、四隅リサイズ、追加・削除。負のサイズやページ外への移動が発生しないこと。
- 枠線をオフにし、レイヤー一覧やコマ選択ツールから再選択。色・幅を変更。
- コマと4種類の吹き出しを重ね、選択競合がないこと。コマ編集でセリフの配置・文字サイズが変わらないこと。
- コマ編集、テンプレート変更、追加・削除をUndo/Redo。吹き出しを再選択したときアコーディオン開閉が保持されること。
- 縦書き・横書き・フチ・影・個別回転・しっぽ・手動クリップを編集。
- ZIP保存→別セッションで再読込→編集。セリフJSON読込でコマが維持されること。不正ZIP/JSONで現在の編集が消えないこと。
- PNGが指定ピクセル寸法で、背景・枠・セリフと装飾を含み、ハンドル・選択枠を含まないこと。
- v1.55のZIP/セリフJSONとPNG/JPEG/WebP画像を開き、従来編集・保存・出力を確認。勝手にコマが追加されないこと。

以上を確認後にmainへのマージと本番反映を行います。
