# Comic-Lab v2.0-alpha.2 — コマ内画像

開発ブランチは `feature/v2-panel-layout`。既存のCloudflareプレビューを使用します。

https://feature-v2-panel-layout-comic-lab.kairi-sakusaku.workers.dev/

main、本番Workers、旧Pages設定、Wranglerのプレビュー設定、シークレットは変更しません。

## 使い方

1. 新規漫画ページでコマを選択し、右側の「画像を読み込む」からPNG・JPEG・WebPを選びます。初期配置は中央Coverです。
2. コマのプロパティで「コマ枠を編集／内部画像を編集」を切り替えます。初期状態はコマ枠です。画像のないコマでは内部画像を選べません。
3. 内部画像を選ぶとガイドがオレンジになり、枠のサイズハンドルが隠れます。コマ内をドラッグすると画像だけが動きます。タッチ操作も同じPointer Eventsを使用します。
4. Coverは全面を覆い、Containは全体が見える倍率へ中央配置します。その後も自由に移動・拡大できます。倍率スライダー・数値入力は画像の中心を固定します。X/Yはコマ左上からの相対ピクセル座標です。
5. 「表示位置をリセット」は現在の倍率で中央へ移動。「初期倍率へ戻す」は現在のCover/Contain方式とコマ寸法から倍率を再計算し、画像中心を維持。「コマに合わせ直す」は倍率と位置を同時に再配置します。
6. 「画像を変更」は新素材を中央Coverへ配置。「画像を削除」はコマ枠を保持します。画像操作はUndo/Redoできます。画像のドラッグは1回の操作として記録します。
7. コマ枠を移動すると画像も追従します。枠のサイズ変更では画像の原稿上の位置・倍率・縦横比を維持します。左上の基準位置が動く場合は相対オフセットを補正し、表示領域だけを変更します。必要に応じて合わせ直します。
8. 画像入りの作品はプロジェクトZIPで保存・復元します。セリフ設定JSONは引き続きセリフ専用です。PNGには画像・枠線・セリフを原寸で描画します。

スマートフォンでは上部の「プロパティ」から右パネルを開いて操作します。

## 設計と互換性

- Projectのv2形式を任意の `assets` 素材カタログと `panel.image` で拡張。alpha.1の画像なしコマ、v1.55の画像モードには新規項目を強制補完しません。
- 素材カタログはID・ZIPパス・元寸法・MIME・ファイル名だけ。画像の元バイト列と表示用URLはDocumentの素材キャッシュに置き、Projectや履歴へBase64画像を埋め込みません。
- コマ内画像はassetId・offsetX/Y・scale・fitMode・元寸法を保存。変換処理はコマの頂点処理と分離しています。
- 同じバイト列の使用中素材は複数コマで共有。ZIPには使用中の素材のみを `assets/images/<id>.<ext>` として1回保存します。
- 差し替え・削除後も履歴用キャッシュを保持するため、Undo/Redoで元画像を復元できます。別の原稿やZIPを開くと履歴とキャッシュを入れ替えます。
- コマの4頂点からclipPathを生成する共通SVG処理を画面とPNGで共有。ページ背景→全コマ画像→全コマ枠→吹き出し・セリフの順です。編集ガイドは別描画で出力に含めません。
- 読込中に選択コマ・原稿が変わると配置を中止します。ZIPは全素材のデコード・寸法・形式確認後に原稿を置き換えるため、失敗時は現在の編集を保持します。
- コマ画像は1枚2,000万画素・一辺20,000pxまで。履歴素材を含め100枚・合計40MB・合計8,000万画素まで。上限時はZIP保存・再読込で未使用の履歴素材を解放できます。
- プロジェクトZIPは従来どおり50MB、展開後100MBまで。画像素材に対応して内部ファイル数は最大102。安全な素材パスのみ許可し、欠落素材・未知形式・不正な位置や倍率を拒否します。

## 検証

122件の `npm test`、TypeScript検査を含む `npm run build`、`git diff --check` が成功しています。

- Cover/Containの寸法と中央配置、中心を固定した倍率変更、コマ移動時の画像追従と、四隅リサイズ時の原稿上の画像位置・倍率維持。
- 実際のAppハンドラーで画像読込・共有・差し替え・削除、ズームとSVG原点移動後の画像ドラッグ、ドラッグ1回のUndo/Redo、ZIP保存・復元。
- 読込中の選択変更・破損画像・素材欠落ZIPで編集を保持。
- 同一素材のZIP重複除外、使用していない履歴素材の保存除外、セリフJSONでコマ画像を維持。
- PNGのCanvasパイプラインへ画像付きSVGを渡すことと原寸出力（DOM・Canvasを代替したハンドラーテスト）。
- 独立SVGラスタライザーで1200×1800pxのページに3つの画像コマと空コマ・吹き出しを描画。コマ外のピクセル、Contain余白、枠線が画像より前面に出ること、ZIP復元前後のPNG完全一致を検証。
- alpha.1のコマ割り検証PNGと、v1.55の回転・ギザギザ・手動クリッピングを含む検証PNGが改修前とバイト単位で一致。

## 未確認事項と対象外

実ブラウザ用ツールがないため、実機でのマウス／タッチのポインター捕捉、IME、画像デコードの端末差、実ダウンロード、ブラウザCanvasによるPNG生成は未確認です。自動ハンドラーテスト・独立SVGラスタライザーでの確認とは区別しています。

プレビューの画面下が **v2.0-alpha.2** であることを確認し、実画像のPNG/JPEG/WebPで上記操作、別セッションでのZIP復元、PNGの見た目一致を確認してください。正式版への統合はユーザー確認後です。

斜めコマ、分割・統合、画像コマレイヤー、吹き出しの親子関係・追従・自動クリッピング、AI機能は追加していません。
