# Comic-Lab v2.5α：コマ・吹き出し連動とクリック式統合

開発ブランチ：`feature/v2-panel-layout`。正常動作の基準コミット：`2488a19`（v2.42）。この基準にはv2.41α `b6864c3`の背景コマ位置ずれ修正と、v2.42の通常コマ不透明化が含まれます。

プレビュー：https://feature-v2-panel-layout-comic-lab.kairi-sakusaku.workers.dev/

## データ・座標の扱い

- `Balloon.panelId`を所属として使用し、任意の`panelTrim`を追加。欠落時は有効な所属コマが通常ならON、背景ならOFF。旧ページで所属がない吹き出しには自動所属・自動移動を行わない。画像編集形式は引き続き画像全体を仮想コマとする。
- 所属は描画レイヤーと独立。吹き出しは従来どおりコマ画像・枠線より手前に描く。ページ・多角形・文字・手動クリップは原稿座標を使用し、表示倍率は操作座標変換だけに使用する。
- コマ移動では所属する吹き出し全体を同じ差分だけ移動。サイズ変更では外接矩形内の中心の相対位置を維持し、本体・文字枠・フォントのサイズ、回転、しっぽ、装飾を保持。頂点編集・画像編集では吹き出しを動かさない。
- 手動クリップは内側、所属コマの多角形クリップは外側。コマクリップは文字を含む全体に適用。コマ追従・貼り付けでは手動クリップも一緒に平行移動し、切り抜いた構図を維持。従来の直接ドラッグでは原稿に固定した手動範囲という既存仕様を維持する。
- ZIPは既存シリアライズ・検証・素材保持処理を利用。セリフJSONにも任意の所属・トリミング情報を保持するが、従来どおりコマ割り・画像は含めない。参照するコマがない場合は所属なしとして表示し、プロパティで再指定できる。元のID・座標は書き換えない。

## 操作

新規ページでは最初のコマを選択。空白ページは選択なし。コマ内部・枠線なしコマも直接クリックでき、吹き出しは編集ツールにかかわらず直接選択できる。背景のヒット領域は通常コマより背面、コマのハンドルは吹き出しより前面に置く。ハンドルは36画面pxの当たり判定を持つ。移動開始は4画面pxのしきい値でクリックと区別する。

新規吹き出しはフォーカス中のコマへ所属し、しっぽと文字枠を含む範囲で内部の配置を探す。収まらない場合も縮小しない。所属先・トリミングは右パネルで変更可能。他コマへ直接ドラッグしても所属は変えない。コマ選択時には所属する吹き出し一覧を表示する。

コピーはアプリ内の一時クリップボード。新IDで独立して貼り付け、元コマに対する相対位置を貼り付け先へ写す。書式のみコピーは本文を空にする。Ctrl/⌘ C・V、従来のDによる複製を利用可能。入力欄ではネイティブの文字操作を優先する。

所属する吹き出しがあるコマの削除は「一緒に削除／所属解除／キャンセル」。分割時に中心がガターや外側なら、所属先の選択を確定するまで作品を変更しない。

## クリック式統合とサイズ合わせ

1. 統合元Aを選択し「コマを統合」。Aは青、調整なし候補は緑の破線＋✓、調整ありは黄色の点線＋△。
2. 候補を直接クリック。統合モードのヒット判定は吹き出し・ハンドルより優先。対象外クリックでは変更しない。Esc／キャンセルで解除。
3. 調整ありは変更前後の位置・寸法・変更する端を表示し、確認するまで変更しない。両方に画像がある場合は画像を選択。
4. Aを固定し、左右統合ではBの上下端、上下統合ではBの左右端だけを合わせて統合。画像の原稿上の位置・倍率を維持。両コマの吹き出しは位置を動かさず新コマへ引き継ぐ。サイズ合わせと統合は1回のUndo/Redo。

対象はロックされていない通常の軸平行長方形。間隔はページのガター以下。対象寸法差と対応する両端のずれを**それぞれ**`min(A寸法×0.1, 50px)`以下で検証する。定数は`src/merge-candidates.ts`で管理。斜め・離れたコマ・不正形状・他の通常コマとの重なりが増える候補を除外する。調整後の形状は既存バリデーター、統合は既存`mergePanels`を利用する。

## 小工程ごとの検証

- データ／座標処理：配置、所属、移動・サイズ追従、頂点編集不変、コピー、削除、分割、候補の境界値と画像位置維持を追加。UI接続前に156件成功。
- 選択／連動UI：初期フォーカス、枠線なし選択、タッチ相当の微小移動、ハンドルの描画順、直接吹き出し選択、所属変更、トリミング、別コマ貼り付け、入力欄のコピー優先を確認。
- 統合UI：候補ハイライト、確認前・キャンセル後のデータ不変、実行後の所属、1回のUndo、両画像からの選択を実際のReactハンドラーで検証。分割の所属選択と削除の3選択肢・Undoも確認。
- 保存／出力：所属・トリミング・手動クリップ・回転・装飾のZIP／JSON保持、参照先がない旧データの保持、出力からのガイド除外を検証。

最終：`npm test` **163件成功（31ファイル）**、`npm run build`、`git diff --check`成功。

独立したResvg描画でも以下を確認：矩形コマの切り抜き／トリミングOFFのはみ出し／手動クリップとの交差／斜め多角形の境界を画素比較。4種類×トリミングON/OFFの8パターン（縁取り・影・回転・手動クリップ併用）で、実際のZIP保存・読込前後のPNG画素が一致。v2.42の背景描画検証も再実行し、通常コマへの透けが再発しないことを確認。

## 制約と未確認範囲

この環境にはブラウザ操作ツールがないため、実ブラウザでの手動操作、タッチ実機、日本語IME、Canvasの実レンダリングは未確認。Reactのイベント経路、SVGと独立ラスタライザーの画素、Canvasへの受け渡しを自動テストで確認している。細いコマでは元サイズを維持するため、新規吹き出し全体が収まる保証はなく、トリミングOFFや手動位置調整を利用できる。

コピーはOSの共有クリップボードではなく、このタブ内で使用する。自動サイズ合わせの許容値設定画面、斜めコマのクリック統合、AI、コマ自動認識は追加しない。

main・本番Worker・旧Pages・Wrangler・Secretsは変更せず、既存Draft PR #1とalphaプレビューでレビューする。
