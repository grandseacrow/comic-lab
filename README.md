# comic.lab — Balloon Editor v1.2

完成済みの漫画画像へ、SVG吹き出しと編集できる日本語セリフを重ねるクライアントサイドアプリです。
Vector-Labとは独立したプロジェクトです。

## 起動と検証

Node.js 24推奨。

```sh
npm ci
npm run dev
npm test
npm run build
```

`dist/` をCloudflare Pagesなどの静的ホスティングへ配置できます。サーバーAPI・認証・外部DBはありません。

## 使い方

1. PNG・JPEG・WebPを読み込むか「サンプルで試す」を選びます。
2. 楕円・角丸四角の吹き出し、または「文字のみ」を追加します。
3. 本体をドラッグして移動し、右下の四角いハンドルでサイズを変更します。
4. しっぽのPを先端、A・Bを付け根としてドラッグします。表示切替・左右／上下反転もできます。
5. 右のプロパティでセリフ、縦横方向、フォント、太字、色、行間、字間、余白を編集します。
6. 「プロジェクト保存」で元画像と編集可能なJSONをZIP保存します。「プロジェクトを開く」で復元できます。
7. 「PNG書き出し」で元画像と同じピクセル寸法の完成原稿を保存します。

レイヤー一覧の上ほど手前です。選択後の矢印で順序変更、複製、削除ができます。
スマートフォンでは上部のツール／プロパティからパネルを開きます。

- パン：移動ツール、またはSpace＋ドラッグ
- 拡大縮小：下部の＋／−、またはCtrl / ⌘＋ホイール
- 取り消し：Ctrl / ⌘ Z
- やり直し：Ctrl / ⌘ Shift Z、Ctrl / ⌘ Y
- 複製：Ctrl / ⌘ D
- 削除：Delete / Backspace
- ZIP保存：Ctrl / ⌘ S

入力欄にフォーカス中はアプリのショートカットを実行しません。自動保存はありません。
PNG書き出しでは編集可能なプロジェクトは保存されないため、再編集する場合はZIPも保存してください。

## v1.2の「文字のみ」

左の作成ツールに「文字のみ」を追加しました。文字のみを選択すると、日本語の縦横方向、本文、フォント、サイズ、色、文字領域の位置・寸法など、文字用の設定だけを表示します。
文字領域のドラッグと右下ハンドルで移動・サイズ変更できます。領域を超えても初期設定では指定文字サイズを維持します。
レイヤー選択・並べ替え・複製・削除・Undo/Redo・ZIP保存は既存の仕組みを共用します。

保存形式version 1とレイヤー配列 `balloons` は維持し、`kind: "text"` で独立したテキストレイヤーを区別します。既存の `ellipse` / `rounded` は変換しません。
共通レコードの吹き出し用フィールドは互換性のため残しますが、文字のみでは本体・背景・枠線・しっぽを一切描画しません。PNGには日本語の文字輪郭だけを含め、編集用のヒット領域・点線・ハンドルは含めません。

自動テスト39件と本番ビルドを通過。文字のみの共通SVGを1000×700pxのPNGへラスタライズし、背景画像の色が文字領域内でも保持されること、縦横・ゴシック／明朝の表示、指定サイズの維持、ZIP復元後のPNGバイト列一致を確認しました。既存吹き出しのv0.1.1検証PNGも改修前と一致しました。実ブラウザでのドラッグ・Canvas出力は未確認です。

## v0.1.1の文字枠・はみ出し・角丸

- 文字枠は背景・境界線を持ちません。文字入力中、または操作対象が「文字枠だけ編集」の間だけ薄い点線ガイドを表示します。ガイド・ハンドルはPNGへ出力しません。
- 「操作対象」で本体＋文字／本体だけ／文字枠だけを選べます。文字枠の移動・サイズ変更は本体と独立しています。本体のリサイズや形状変更では文字枠を変更しません。
- はみ出しの初期値は「そのまま表示」です。文字サイズを維持し、文字のクリッピングを行いません。原稿の外側だけが出力範囲外です。
- 「サイズを維持して警告」は文字枠や吹き出し本体からのはみ出しを通知します。出力は可能です。
- 「自動フィット」は選択時だけ文字枠内に収まる表示サイズを計算します。指定サイズは `style.size` として別途保持し、モード解除時に復元します。文字枠座標・原文・手動改行は変更せず、指定サイズで決まった自動折り返しも再配置しません。新規作成時の改行は「入力した改行のみ」で、サイズ変更による勝手な改行を防ぎます。必要な場合は従来の自動折り返しも選択できます。表示時の字間も指定サイズとの比率で縮小します。
- 角丸の丸みは0〜100%。0%は四角形、100%は各辺の半分まで丸めた形状です。サイズ変更でも割合を保持します。楕円ではスライダーを無効にします。
- 両形状の新規吹き出しはしっぽあり。オフにしてもA/B/Pを保持し、オンで同じ形状へ戻ります。
- 保存形式のversionは1を維持し、`textFrame`、`roundness`、`style.overflowMode`、`style.wrapMode`を追加します。旧ZIPには旧配置を再現する文字枠、丸み24%、そのまま表示、従来の自動折り返しを補います。既存のしっぽなし設定は維持し、フラグ自体がないときだけありに補います。
- Undo/Redoは新しい設定と独立した文字枠編集にも対応します。

## データ・描画方式

- 原稿座標は元画像のピクセル単位。表示倍率から分離しています。
- 背景の元バイト列は変更せずZIPへ格納します。
- 吹き出し本体としっぽはPaper.jsの和集合による単一パスで描画します。
- フォントはSIL Open Font LicenseのNoto Sans JP / Noto Serif JPを同梱しています。
- 日本語の縦書きはOpenTypeのvert / vrt2置換で縦書き字形を取得します。英数字の連続部分だけを横倒しにし、日本語全体は回転しません。
- 文字はfontkitでSVG輪郭へ変換します。編集画面とPNG合成で同じ形状・配置データを使い、出力時のWebフォント参照を不要にしています。
- 単純な禁則処理、自動折り返し、手動改行、はみ出し警告を備えます。縦中横やルビは対象外です。
- フォントにない文字を検出するとPNG出力を停止し、修正を案内します。

保存形式は `project.json` と `assets/background.png` / `.jpg` / `.webp` を含むZIPです。
JSON形式バージョンは1です。選択状態・倍率・編集ハンドル・履歴は保存しません。

画像は50MB・2,000万画素・一辺20,000px以下、吹き出し200個まで。
ZIPは50MB、展開後100MB、内部ファイル10件以下に制限します。
不明なファイルパス、重複エントリ、不正な型・数値・色・参照は拒否します。
復元準備が完了してから現在の原稿を入れ替えるため、読込失敗時は原稿を保持します。

## 自動検証と未確認事項

`npm test` は従来機能に加え、指定サイズ維持、任意の自動フィット、文字枠の独立編集、丸み0/24/100%、しっぽ再表示、旧形式移行、ZIP往復後の同一SVG、Undo/Redoを検証します。
`npm run build` はTypeScript検査と本番ビルドを行います。
追加で、共通SVGを別のSVGラスタライザでPNG化し、日本語縦書きの句読点・括弧・小書き文字・長音符・英数字、および横書きの輪郭表示を目視確認しました。これはブラウザCanvas出力の検証とは別です。

この実装環境ではSites用ブラウザ操作ツールが提供されていないため、実ブラウザでのマウス／タッチ操作、IME、ダウンロード、Canvasによる最終PNG生成、Safari実機での表示一致は未検証です。v0.1.1では共通SVGをラスタライズし、1200×1000pxの原寸PNGに吹き出し外の文字が含まれること、ZIP保存・復元後のPNGバイト列一致を追加確認しています。自動テストだけで仕様書の全合格基準を確認済みとはしていません。
手動受入手順は `docs/acceptance.md` にあります。

## Cloudflare Pages

`.github/workflows/ci.yml` はpush / Pull Request時にテストとビルドを実行します。
`.github/workflows/deploy.yml` はmainの変更時および手動実行に対応します。
初回はCloudflare PagesにDirect Uploadプロジェクト `comic-lab`（production branch: main）を作成し、このリポジトリのActions Secretsへ以下を登録してください。

- `CLOUDFLARE_API_TOKEN`：対象アカウントのCloudflare Pages Edit権限
- `CLOUDFLARE_ACCOUNT_ID`：対象アカウントのAccount ID

Secrets未登録時はデプロイをスキップします。Vector-Labのプロジェクト・Secrets・ワークフローは変更しません。
Pages側のGit連携を使う場合は `npm ci && npm run build`、出力先 `dist` を指定し、Actionsからのデプロイと二重実行しない構成にしてください。

Sites側のWeb版は `.openai/hosting.json` のプロジェクトに独立して配置します。
GitHubへのpushだけでSites版が更新される構成ではありません。
